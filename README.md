> I made this for myself and friends in my own time and I don't plan on expanding upon it.

This is a super simple tool that was designed to calculate how many Dining Dollars is left in a college account, and how much can be spent each day to fully utilize the amount.

There are two options that provide some flexability on how you spend them. One counts weekends, and the other counts days that my university does not have classes.
